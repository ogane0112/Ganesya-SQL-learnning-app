# Design System

このアプリの UI は「**青 1 色をアクセントに、それ以外は無彩色**」というルールで統一しています。
すべての画面が `src/components/ui/` のプリミティブ（Button / Field / Card / Badge / Alert / Icon）を通して描画されるので、角丸・余白・フォーカスリングは自動的に揃います。

## 1. 色 — 意味で選ぶ

| 用途 | 色 | 意図 |
|---|---|---|
| 主要アクション・アクティブなナビ・リンク・フォーカスリング・進捗バー・難易度ドット | `blue-600` | **アクセントは青だけ。** 「青 = 操作できる／重要」を一度覚えれば、どの画面でも迷わない |
| 選択状態・軽い強調 | `blue-50` / `blue-700` | 同じ青の淡色。新しい色を増やさない |
| ページ背景 / カード / 罫線 | `slate-50` / `white` / `slate-200` | 階層は影ではなく 1px の罫線と余白で作る（並んだカードが騒がしくならない） |
| 正解 | `emerald` | フィードバック専用 |
| 不正解 | `amber` | 「間違えた」は学習の一部であって失敗ではないので、赤を使わない |
| SQL エラー / システム障害 | `red` | 「壊れた」だけを赤にする。不正解と明確に区別 |

装飾のために有彩色を使うことはありません。色が出てきたら必ず意味があります。

## 2. タイポグラフィ

- 本文: システム Sans（Inter / Noto Sans JP フォールバック）
- **SQL に関わるものはすべて等幅**（テーブル名・列名・結果ヘッダ・エラーメッセージ・問題番号）。「これはコードとして扱われる文字列だ」と一目で分かる
- 見出しは `tracking-tight`、本文は `leading-relaxed`

## 3. 形と間隔

- カード `rounded-xl (12px)`、コントロール `rounded-lg (8px)`、バッジ `rounded-full`
- 8pt グリッド。ページ余白 `px-4 sm:px-6`、セクション間 `gap-6`
- すべてのタップ対象は 44px 以上（要件 9.7）
- フォーカス: `.focus-ring`（青 2px + オフセット）を全コントロールに

## 4. ボタン階層

1 画面に `primary`（青塗り）は 1 つだけ。次に取るべき行動を曖昧にしないため。

- `primary` — 実行 / ログイン / 登録 / 問題を解く
- `secondary` — 白 + 罫線。代替行動（パスキー、次のヒント）
- `ghost` — 装飾なし。ナビ・ログアウト・「答えを見る」（3 回不正解で `primary` に昇格）

## 5. 画面ごとの意図

### Home
- 1 つの約束（見出し + 説明）と 1 つの主要 CTA
- 3 枚のカードは初訪問者の 3 つの疑問「速い？ 安全？ 詰まったら？」に対応

### 問題一覧
- 進捗は数字だけでなく**バー**で見せる（このページのモチベーションはここ）
- 難易度は `★☆` ではなく青いドット。フォントに依存せず、パレットと調和する
- ステータスは Badge の色相で伝え、正解にはチェックアイコンを添える

### 問題を解く
レイアウトは作業の流れそのもの:

```
問題文（常に表示）
┌ 参照 ─────────┐ ┌ 作業 ───────────────────────┐
│ テーブル定義      │ │ エディタ  [query.sql]   [▶ 実行] │
│  employees        │ │                                  │
│   id name dept …  │ ├ 実行結果 ───────────────────────┤
│  ▸ CREATE 文を表示 │ │ ✅/❌ バナー → 結果テーブル       │
└───────────────────┘ │ 💡 ヒント（失敗を見た場所に助けを置く） │
                       └──────────────────────────────────┘
```

- テーブル定義は DDL をそのまま貼らず、**テーブル → 列チップ**に構造化。DDL は `details` で折りたたみ
- 実行ボタンはエディタのツールバー内（操作対象のすぐ隣）。モバイルではキーボードに隠れないようエディタ下部へ
- 正解バナーに「次の問題へ」を同居させ、成功の直後に次の行動を提示
- ヒントは結果の直下。不正解を見た瞬間に手が届く
- モバイルは同じ 3 領域をタブに（要件 9.7）

### エディタ（Monaco）
- ライトテーマでアプリと同じパレット。キーワードは UI と同じ `blue-700`、文字列 emerald、数値 amber で「構造」と「リテラル」を区別
- スキーマ連動の補完（テーブル / 列 / キーワード）
- `Ctrl/⌘ + Enter` で実行。ショートカットはツールバーの `kbd` で常時提示

### ログイン / 登録
- 同じ `AuthShell` で描画し、兄弟画面であることを見た目で示す
- ラベルは常時表示（プレースホルダ代替にしない）。エラーは `aria-describedby` で入力に紐づけ
- パスキーは対応ブラウザでのみ `secondary` として提示（要件 9.1）。主導線は常に ID + パスワード
